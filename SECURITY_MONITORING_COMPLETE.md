## 🚀 Quick Start (10 minutes)

### Step 1: Enable Email Alerts (5 min)

1. Go to: https://app.supabase.com
2. Select "ATJ-ERP" project
3. Settings → Notifications
4. Enable security alerts
5. Add your email

### Step 2: Set Up Weekly Reminder (5 min)

**Option A: Calendar**
- Add recurring event: Every Monday, 15 minutes
- Title: "Supabase Security Check"

**Option B: GitHub Actions**
- Already set up! Runs every Monday
- Check GitHub Actions tab for reminders

### Step 3: Start Tracking (Ongoing)

1. Update `docs/security-tracking.md` weekly
2. Record security score
3. Note any findings

## 📅 Weekly Routine (15 minutes)

**Every Monday:**

1. **Run Security Advisor** (5 min)
   ```
   Supabase → Security → Security Advisor → Run scan
   ```

2. **Review & Fix** (5 min)
   - Fix any new issues
   - Update tracking document

3. **Update Documentation** (5 min)
   - Record security score
   - Note findings in tracking file
